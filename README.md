
Простое веб-приложение на Flask для управления списком задач.
Данные хранятся в файле `tasks.json` внутри Docker-контейнера.

- Просмотр списка задач
- Добавление новых задач
- Удаление задач

- Python 3
- Flask
- Docker
- JSON

1. Собрать образ: `docker build -t todoapp .`
2. Запустить контейнер: `docker run -d -p 127.0.0.1:8000:8000 todoapp`
3. Открыть в браузере: http://127.0.0.1:8000
